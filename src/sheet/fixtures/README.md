# Spreadsheet test files

Small .xlsx files saved by real spreadsheet programs, used by `../xlsx.test.ts` to check
the reader and the formula engine against the values those programs stored.

| File | Saved by | Source | Licence |
|---|---|---|---|
| `calamine-errors.xlsx` | Microsoft Excel | [tafia/calamine](https://github.com/tafia/calamine) `tests/errors.xlsx` | MIT |
| `calamine-formula.issue.xlsx` | Microsoft Excel | calamine `tests/formula.issue.xlsx` | MIT |
| `calamine-issues.xlsx` | Microsoft Excel | calamine `tests/issues.xlsx` | MIT |
| `calamine-merged_range.xlsx` | Microsoft Excel | calamine `tests/merged_range.xlsx` | MIT |
| `calamine-richtext-namespaced.xlsx` | Microsoft Excel | calamine `tests/richtext-namespaced.xlsx` | MIT |
| `calamine-date.xlsx` | LibreOffice 7.4 | calamine `tests/date.xlsx` | MIT |
| `calamine-date_1904.xlsx` | LibreOffice 7.3 | calamine `tests/date_1904.xlsx` | MIT |
| `poi-shared_formulas.xlsx` | Microsoft Excel | [apache/poi](https://github.com/apache/poi) `test-data/spreadsheet/shared_formulas.xlsx` | Apache-2.0 |
